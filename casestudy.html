Case Study: ATMoS Scientific Modelling on Repurposed Legacy Hardware

A Case Study by Atkinson IT Ltd

Project Overview

As part of a STEM degree in Planetary Science & Astronomy, Atkinson IT Ltd’s founder, Bernard Atkinson, needed to run a full atmospheric escape modelling pipeline using ATMoS — a demanding scientific modelling suite used in planetary science research.

ATMoS was incompatible with modern Apple Silicon Macs, so Bernard rebuilt an older Intel-based iMac from the ground up — transforming obsolete equipment into a stable, Linux-based scientific workstation capable of running 108 independent simulations.

This project demonstrates Atkinson IT Ltd’s ability to:

  • Revive legacy hardware
  • Deploy Linux systems for specialist workloads
  • Work around platform incompatibilities
  • Automate complex modelling pipelines
  • Securely transfer and process large datasets

The Challenge

The project faced two major obstacles:

  1. ATMoS incompatibility with Apple Silicon (ARM/RISC) — ATMoS requires x86_64 architecture, Linux-compatible scientific libraries, and a stable POSIX environment.
  2. Outdated Intel iMac — unsupported macOS versions, dependency conflicts, poor performance, and inability to run ATMoS natively.

The solution required a complete rebuild, Linux deployment, scientific library installation, automated batch processing, and secure data transfer.

The Solution

1. System Rebuild & Linux Deployment

The Intel iMac was wiped, rebuilt, and configured with Ubuntu Linux for stability and performance — optimised for scientific workloads.

2. Scientific Environment Setup

Installed Python 3.x, ATMoS suite, and scientific libraries (NumPy, SciPy, Pandas, Matplotlib) in isolated environments to avoid dependency conflicts.

3. Automated Multi‑Run Pipeline

Developed a Python-driven workflow to run 108 simulations, manage parameter sweeps, collect outputs, and generate visualisations — turning a manual process into a repeatable automated pipeline.

4. Secure Data Transfer

Configured SSH for secure remote access and used Cyberduck (SFTP) for encrypted transfer of raw outputs, processed datasets, and graphs.

5. Data Analysis & Visualisation

Generated radiation flux curves, atmospheric escape rate graphs, time-dependent evolution plots, and comparative scenario charts — forming the analytical backbone of the dissertation.

Results

  • Legacy Intel iMac became a fully functional scientific workstation
  • 108 atmospheric simulations completed successfully
  • Automated Python scripts processed all outputs
  • Secure SSH/SFTP workflow ensured smooth data transfer
  • Delivered publication-quality graphs and datasets
  • Successfully worked around ATMoS’s incompatibility with ARM/RISC Macs
  • Contributed to a strong academic result (expected 2:1, with a realistic chance of a First)
