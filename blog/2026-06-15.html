Weekly SME IT Update

15 June 2026

Home › Blog › Weekly SME IT Update

Windows Recall privacy controls clarified

Microsoft has responded to privacy concerns around its new “Recall” feature on Copilot+ PCs. SMEs can now centrally disable Recall using Intune or Group Policy, which is strongly recommended for any business handling sensitive data or operating under GDPR obligations. Expect more updates as Microsoft continues tightening the feature’s security model.

Microsoft Teams introduces stricter meeting defaults

Teams is rolling out new security defaults for meetings, including:
• external participants held in the lobby by default
• tighter screen‑sharing permissions
• automatic expiration of meeting chats These changes reduce accidental data exposure and help SMEs stay compliant without manual configuration.

NCSC issues warning on QR‑code phishing (“quishing”)

The UK’s National Cyber Security Centre has published fresh guidance on QR‑based phishing attacks. Attackers are increasingly using QR codes to bypass email filtering and redirect users to credential‑harvesting sites. SMEs using QR codes for onboarding, Wi‑Fi access, or event check‑ins should ensure staff know to treat QR codes with the same caution as email links.

Dropbox Advanced storage policy changes

Dropbox has adjusted how pooled storage works for business accounts. Some SMEs may see reduced available storage or increased costs depending on licence mix. A quick licence audit can prevent unexpected overage charges and ensure teams aren’t paying for unused capacity.

Apple issues more urgent patches

Apple has released another set of security updates for iOS, iPadOS and macOS, addressing actively exploited vulnerabilities. SMEs should ensure automatic updates are enabled and confirm older devices are still receiving security patches.

Baldur’s Gate 3 on macOS — a small but relevant note

Some macOS users have reported issues launching or updating Baldur’s Gate 3, linked to sandboxing restrictions and how the game handles large asset updates. While this is “just a game”, it highlights a broader SME reality: macOS can still be tripped up by applications that don’t fully align with Apple’s security and packaging model. Creative tools, engineering apps, and legacy utilities can behave similarly. Standardising install methods and keeping devices fully patched helps reduce these issues.
