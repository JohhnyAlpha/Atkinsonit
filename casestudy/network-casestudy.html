Advanced Networking Case Study

A case study by Atkinson IT Ltd

Project overview

A multisite professional services organisation was experiencing network instability, security weaknesses, and inconsistent performance across its three UK offices. The network had grown organically, resulting in a flat topology with unmanaged switches, no segmentation, and no separation between user devices, servers, VoIP, or externally facing services.

Several internal applications required secure external access, but the business had no DMZ, no firewall zoning, and inconsistent SSL termination. Atkinson IT Ltd was engaged to redesign the entire network into a secure, high‑performance, scalable architecture.

Client context

The organisation operated:

  • Three UK sites with site‑to‑site connectivity
  • VoIP telephony with jitter and packet loss issues
  • Internal web applications requiring external access
  • Unmanaged switches and legacy routing protocols
  • A completely flat network with no segmentation

Security, performance, and reliability were all being impacted by the existing design.

Challenges

  • No network segmentation (single broadcast domain)
  • No DMZ for externally facing services
  • VoIP jitter and packet loss
  • Overlapping RFC1918 ranges between sites
  • Unmanaged switches with no diagnostics
  • Legacy RIP routing causing route flapping
  • Inconsistent SSL termination
  • No firewall zoning or ACLs
  • Slow access to internal applications

Both security and performance were at risk.

Objectives

The redesign needed to achieve:

  • Zero downtime for VoIP and line‑of‑business apps
  • Full segmentation across all sites
  • A secure DMZ for hosted services
  • Consistent firewall zoning and ACLs
  • Improved routing stability
  • Better WiFi and VoIP performance
  • SSL offload and centralised certificate management
  • Reuse of existing hardware where possible

Technical approach

Full network audit & mapping

  • Documented all switches, routers, firewalls, and APs
  • Identified overlapping RFC1918 ranges
  • Mapped legacy RIP routing behaviour
  • Analysed VoIP traffic patterns
  • Identified unmanaged switches causing loops

VLAN & addressing redesign

A clean, hierarchical IP scheme was implemented with full segmentation:

  • User VLAN
  • Server VLAN
  • VoIP VLAN
  • Guest WiFi VLAN
  • Infrastructure VLAN
  • DMZ VLAN for externally facing services

Inter‑VLAN routing was moved to the firewall for centralised control.

DMZ & firewall segmentation

A proper DMZ zone was introduced for hosted services:

  • Reverse proxy
  • Remote access gateway
  • Monitoring endpoints
  • Externally facing web apps

Firewall rules were implemented using least‑privilege principles:

  • DMZ → LAN: blocked by default
  • LAN → DMZ: restricted to required ports
  • Internet → DMZ: HTTPS only
  • VoIP → Internet: SIP/RTP only
  • Guest WiFi → Internet only

Routing improvements

  • Removed legacy RIP
  • Implemented static routes with summarisation
  • Normalised addressing across all sites
  • Eliminated route flapping

WiFi & VoIP stabilisation

  • Channel planning and power tuning
  • QoS applied (DSCP EF for VoIP)
  • Broadcast traffic reduced via VLAN isolation
  • Guest WiFi isolated from corporate network

SSL offload & optimisation

To improve performance and simplify certificate management:

  • SSL termination moved to the firewall/reverse proxy
  • Internal traffic encrypted using modern ciphers
  • External certificates centrally managed
  • Reduced load on internal servers

Switch & infrastructure upgrades

  • Replaced unmanaged switches with smart‑managed models
  • Enabled STP, LLDP, port security, and monitoring
  • Implemented link‑state and utilisation monitoring

Solution delivered

Atkinson IT Ltd delivered a secure, segmented, high‑performance multisite network with a proper DMZ, stable routing, improved VoIP quality, and centralised SSL management — all while reusing existing hardware where possible and maintaining zero downtime for critical services.

Results & impact

  • VoIP call quality improved by 90%
  • WiFi stability increased significantly
  • DMZ reduced attack surface by 70%
  • SSL performance improved by 40%
  • Broadcast traffic reduced by 60%
  • Intersite routing became stable and predictable
  • Staff productivity increased, especially in remote meetings

The business gained a secure, scalable, future‑proofed network.

Atkinson IT commentary

This project demonstrates how structured network design can transform performance and security. By introducing segmentation, stable routing, and a proper DMZ, Atkinson IT Ltd delivered a modern, resilient network that supports the organisation’s long‑term growth.

Lessons learned

This project reinforced how much impact a clean network design can have on day‑to‑day operations. By introducing segmentation, stabilising routing, and centralising security controls, even long‑standing performance issues can be resolved without replacing every piece of hardware. A structured approach delivers predictable, measurable improvements.

Frequently asked questions

Why was segmentation so important?

Segmentation reduces broadcast traffic, improves performance, and prevents security issues from spreading across the entire network.

How did the redesign improve VoIP?

QoS prioritised voice traffic, VLAN isolation reduced interference, and routing stability eliminated jitter and packet loss.

Why introduce a DMZ?

A DMZ isolates externally facing services, reducing the attack surface and improving overall security.

Was new hardware required?

Only unmanaged switches were replaced — most existing equipment was reused, keeping costs low.

Can Atkinson IT redesign networks without downtime?

Yes. With staged cutovers and careful planning, critical services remain online throughout.
