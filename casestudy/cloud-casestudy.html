Cloud Migration Case Study

A case study by Atkinson IT Ltd

Project overview

A large multi‑site organisation operating several legacy Microsoft Exchange environments across disparate Active Directory forests needed to modernise its messaging and collaboration platform. The objective was to migrate all users to Office 365 with hybrid identity, SharePoint, OneDrive, and Teams — all delivered with zero downtime and full coexistence throughout the transition. Atkinson IT Ltd designed and delivered the full migration strategy, enabling a seamless shift to a modern cloud‑based productivity platform.

Client context

The organisation operated:

  • Multiple Exchange versions across different geographic sites
  • Several AD forests with inconsistent schema and identity models
  • Ageing hardware approaching end‑of‑life
  • Fragmented collaboration tools and limited mailbox capacity
  • A mix of Windows and macOS clients
  • No unified document storage or mobile device management

The business required a modern, secure, scalable cloud platform without disrupting day‑to‑day operations.

Challenges

The project faced several technical and operational challenges:

  • Multiple legacy Exchange versions
  • Disparate AD forests with inconsistent schema
  • Ageing hardware and storage
  • No modern collaboration tools
  • Limited mailbox quotas and slow search
  • No mobile device management
  • No unified document storage
  • Complex DNS and Autodiscover configuration
  • Mixed Windows/macOS user base

Objectives

Success for this project meant:

  • Zero downtime for all users
  • Full coexistence during migration
  • Preserving multidomain identity
  • Replacing legacy file shares with SharePoint
  • Enabling OneDrive for personal storage
  • Deploying Teams for communication and collaboration
  • Improving security with MFA and Conditional Access
  • Phasing migration to avoid overwhelming support teams

Technical approach

Environment assessment & identity planning

  • Audited all Exchange servers and AD forests
  • Identified schema inconsistencies
  • Mapped mail routing and Autodiscover behaviour
  • Designed hybrid identity using Azure AD Connect
  • Normalised UPNs and SMTP namespaces

This established a clean foundation for coexistence.

Hybrid Exchange deployment

  • Installed hybrid Exchange servers
  • Configured secure mail routing between on‑prem and Office 365
  • Enabled Autodiscover redirection
  • Implemented OAuth‑based authentication
  • Validated coexistence for calendars, free/busy, and mail flow

This enabled seamless mailbox moves.

Mailbox migration

  • Prioritised VIPs and critical teams
  • Used batch migration for large groups
  • Migrated mailboxes using MRS (Mailbox Replication Service)
  • Ensured mobile devices reconnected automatically
  • Validated Outlook profiles and Autodiscover

Users experienced zero downtime.

SharePoint & OneDrive rollout

  • Designed SharePoint site collections to replace legacy file shares
  • Migrated departmental data using the SharePoint Migration Tool
  • Enabled OneDrive for personal storage
  • Implemented retention policies and versioning
  • Delivered user training and adoption guidance

This modernised collaboration across the organisation.

Teams integration

  • Enabled Teams for chat, meetings, and collaboration
  • Integrated Teams with SharePoint document libraries
  • Configured compliance and retention policies

Teams became the organisation’s communication hub.

DNS, security & compliance

  • Updated MX, SPF, DKIM, and DMARC records
  • Implemented MFA and Conditional Access
  • Enabled mailbox auditing and retention
  • Configured antimalware and antiphishing policies

Security posture improved significantly.

Decommissioning legacy Exchange

  • Migrated all mailboxes and public folders
  • Removed hybrid servers after validation
  • Decommissioned legacy hardware
  • Cleaned up DNS and Autodiscover entries

The organisation became fully cloud‑based.

Solution delivered

Atkinson IT Ltd delivered a complete cloud migration solution, moving the organisation from fragmented legacy Exchange environments to a unified Office 365 platform with hybrid identity, modern collaboration tools, and significantly improved security. The migration was executed with zero downtime and full coexistence throughout.

Results & impact

The project delivered measurable benefits:

  • 100% of users migrated to Office 365
  • Zero downtime during the entire project
  • Dramatically increased mailbox sizes
  • Improved search performance
  • SharePoint replaced legacy file shares
  • OneDrive enabled mobile productivity
  • Teams unified communication and collaboration
  • Security strengthened with MFA and Conditional Access
  • Legacy Exchange servers fully decommissioned
  • Significant reduction in operational overhead

  • SharePoint Online
  • OneDrive for Business

Skills demonstrated

Atkinson IT commentary

This project showcased the value of careful planning, phased execution, and deep understanding of hybrid identity and coexistence. By modernising the organisation’s messaging and collaboration stack, Atkinson IT Ltd delivered a secure, scalable, cloud‑based platform that significantly improved productivity while reducing operational overhead.

Lessons learned

Large-scale cloud migrations succeed when identity, coexistence, and user experience are treated as first‑class engineering concerns rather than afterthoughts. This project reinforced the importance of establishing a clean identity foundation before moving any workloads, validating coexistence thoroughly, and phasing migrations to avoid unnecessary disruption. A methodical approach ensured the organisation gained the full benefits of the modern Microsoft 365 platform without operational risk.

Frequently asked questions

How disruptive is a cloud migration for end users?

With the right coexistence model, mailbox moves and service transitions can be completed with no noticeable impact. In this project, users continued working normally throughout.

Do hybrid Exchange servers need to remain in place permanently?

No. Once all mailboxes and public folders are migrated and coexistence is no longer required, hybrid servers can be safely decommissioned.

What happens to legacy file shares during a migration?

They are typically replaced with SharePoint site collections and OneDrive, allowing for better structure, versioning, and remote access.

Is Teams adoption difficult for organisations?

Teams adoption is straightforward when supported by clear guidance and when SharePoint is structured properly from the outset.

Can Atkinson IT support smaller organisations with similar migrations?

Yes. The same principles apply regardless of size, and smaller organisations often benefit even more from a modern cloud platform.
