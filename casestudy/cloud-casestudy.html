Cloud Migration Case Study

A Case Study by Atkinson IT Ltd

Overview

A large organisation operating multiple legacy Microsoft Exchange servers across disparate Active Directory forests needed to modernise its messaging and collaboration platform. The goal was to migrate all users to Office 365 with hybrid identity, SharePoint, OneDrive, and Teams — all with zero downtime.

The Challenge

  • Multiple legacy Exchange versions across different sites
  • Disparate AD forests with inconsistent schema
  • Ageing hardware approaching end-of-life
  • No modern collaboration tools
  • Limited mailbox quotas and slow search
  • No mobile device management
  • No unified document storage
  • Complex DNS and Autodiscover configuration
  • Users spread across Windows and macOS

Constraints

  • Zero downtime for email
  • Coexistence required during migration
  • Multidomain identity had to be preserved
  • SharePoint needed to replace legacy file shares
  • Mobile users required seamless transition
  • DNS changes had to be coordinated across multiple sites
  • Migration had to be phased to avoid overwhelming support teams

What I Did

I designed and delivered a full cloud migration strategy, moving the organisation from legacy Exchange to Office 365 with hybrid identity and modern collaboration tools.

1. Environment Assessment & Identity Planning

  • Audited all Exchange servers and AD forests
  • Identified schema inconsistencies
  • Mapped mail routing and Autodiscover behaviour
  • Designed a hybrid identity model using Azure AD Connect
  • Normalised UPNs and SMTP namespaces

This created a clean foundation for coexistence.

2. Hybrid Exchange Deployment

  • Installed hybrid Exchange servers
  • Configured secure mail routing between on‑prem and O365
  • Enabled Autodiscover redirection
  • Implemented OAuth‑based authentication
  • Validated coexistence for calendars, free/busy, and mail flow

This allowed users to be migrated without interruption.

3. Mailbox Migration

  • Prioritised VIPs and critical teams
  • Used batch migration for large groups
  • Migrated mailboxes using MRS (Mailbox Replication Service)
  • Ensured mobile devices reconnected automatically
  • Validated Outlook profiles and Autodiscover

Users experienced zero downtime.

4. SharePoint & OneDrive Rollout

  • Designed SharePoint site collections to replace legacy file shares
  • Migrated departmental data using the SharePoint Migration Tool
  • Enabled OneDrive for personal storage
  • Implemented retention policies and versioning
  • Provided user training and adoption guidance

This modernised collaboration across the organisation.

5. Teams Integration

  • Enabled Teams for chat, meetings, and collaboration
  • Integrated Teams with SharePoint document libraries
  • Configured compliance and retention policies

Teams became the new communication hub.

6. DNS, Security & Compliance

  • Updated MX, SPF, DKIM, and DMARC records
  • Implemented MFA and Conditional Access
  • Enabled mailbox auditing and retention
  • Configured antimalware and antiphishing policies

This significantly improved the organisation’s security posture.

7. Decommissioning Legacy Exchange

  • Migrated all mailboxes and public folders
  • Removed hybrid servers after validation
  • Decommissioned legacy hardware
  • Cleaned up DNS and Autodiscover entries

The organisation became fully cloud‑based.

Outcome

  • 100% of users migrated to Office 365
  • Zero downtime during the entire project
  • Mailbox sizes increased dramatically
  • Search performance improved
  • SharePoint replaced legacy file shares
  • OneDrive enabled mobile productivity
  • Teams unified communication and collaboration
  • Security improved with MFA and Conditional Access
  • Legacy Exchange servers fully decommissioned
  • Operational overhead reduced significantly
