Disaster Recovery & Business Continuity Case Study

A case study by Atkinson IT Ltd

Project overview

A division of a FTSE100 organisation suffered a severe disaster when water ingress from adjacent building works flooded one of its two server rooms. The incident destroyed the IBM Tivoli TSM tape subsystem, eliminating all onsite backup copies and rendering the room unusable. With critical systems at risk and no operational backup platform, the organisation required a fully functional recovery solution within 48 hours.

Client context

The organisation operated a large, mixed‑platform environment including:

  • Hundreds of Windows and Linux servers
  • VMware virtualisation
  • Multidomain authentication
  • Enterprise file services
  • IBM Tivoli TSM tape‑based backups

The loss of the tape library removed the only onsite backup tier, leaving the business exposed to data loss.

Challenges

  • IBM robotic tape library destroyed by water
  • All onsite backup copies lost
  • Server room unusable due to flooding
  • No operational backup or recovery capability
  • Replacement hardware months away
  • Critical systems at immediate risk
  • Large, complex, multidomain environment

This was a genuine business‑critical emergency requiring immediate action.

Objectives

The recovery effort needed to achieve:

  • Operational backup capability within 48 hours
  • Critical‑first protection strategy
  • Support for Windows, Linux, VMware, and file services
  • A long‑term DR/BCP architecture
  • Minimal disruption to production workloads
  • Safe migration path to a new tape library

Technical approach

Emergency NetApp backup platform (48‑hour deployment)

To restore backup capability immediately:

  • Deployed a NetApp storage system as a temporary backup target
  • Configured high‑capacity aggregates for rapid ingestion
  • Integrated with existing servers and VMware hosts
  • Enabled snapshots for instant recovery
  • Implemented SnapMirror for offsite replication
  • Prioritised critical systems for first‑wave protection

This restored backup capability within the 2‑day deadline.

Critical‑first migration

Systems were triaged into tiers to maximise resilience:

Tier 1 — Critical

  • Financial systems
  • Authentication services
  • Core databases
  • Line‑of‑business applications
  • VMware management infrastructure

Tier 2 — Important

  • Departmental file shares
  • Secondary applications
  • Internal web services

Tier 3 — Low priority

  • Archive data
  • Legacy systems
  • Non‑production workloads

New tape library design & commissioning

I oversaw the design and commissioning of a new server room and multi‑cabinet IBM tape library with:

  • Robotised tape handling
  • Integration with Tivoli TSM
  • Redundant power and cooling
  • Fire suppression
  • Fibre Channel zoning and power distribution
  • Environmental controls and tape robot calibration

This became the long‑term archival tier.

Reverse migration & DR architecture

After the new tape subsystem was commissioned:

  • Backups were migrated back to tape
  • The NetApp system was repurposed offsite
  • SnapMirror replication configured for DR
  • A tertiary cold‑standby DR site established
  • Regular failover tests implemented

This created a three‑tier resilience model:

  • Local snapshots (instant recovery)
  • Tape library (long‑term retention)
  • Offsite NetApp (DR/BCP replication)

Solution delivered

Atkinson IT Ltd delivered a complete emergency recovery and long‑term DR/BCP solution, restoring backup capability within 48 hours, protecting critical systems first, and implementing a modern, multi‑tier resilience architecture.

Results & impact

  • Full backup capability restored within 48 hours
  • Zero data loss despite the disaster
  • Critical systems protected first
  • New enterprise‑grade tape library commissioned
  • Offsite DR replication established
  • Long‑term BCP architecture implemented
  • Improved RTO/RPO across all systems
  • Modern, multi‑tier backup strategy deployed

This transformed a near‑catastrophic incident into a resilient, future‑proofed DR/BCP platform.
