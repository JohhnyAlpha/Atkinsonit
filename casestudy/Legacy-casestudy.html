Case Study: ATMoS Scientific Modelling on Repurposed Legacy Hardware

A case study by Atkinson IT Ltd

Project overview

As part of a STEM degree in Planetary Science & Astronomy, Atkinson IT Ltd’s founder, Bernard Atkinson, needed to run a full atmospheric escape modelling pipeline using ATMoS — a demanding scientific modelling suite used in planetary research. ATMoS was incompatible with modern Apple Silicon Macs, requiring an x86_64 Linux environment with specific scientific libraries.

To overcome this, Bernard rebuilt an ageing Intel‑based iMac from the ground up, transforming obsolete hardware into a stable Linux‑based scientific workstation capable of running 108 independent simulations.

Client context

The modelling work required:

  • A stable x86_64 Linux environment
  • Scientific Python libraries and dependencies
  • Automated batch processing for large simulation sets
  • Secure transfer of large datasets
  • Reliable visualisation and analysis tools

The only available hardware was an outdated Intel iMac no longer supported by modern macOS versions.

Challenges

  • ATMoS incompatible with Apple Silicon (ARM/RISC)
  • Legacy Intel iMac with unsupported OS and dependency conflicts
  • Need for a stable Linux scientific environment
  • Large‑scale simulation workload (108 runs)
  • Secure transfer of large datasets and outputs

The solution required a complete rebuild, Linux deployment, scientific library installation, automated batch processing, and secure data transfer.

Objectives

The project needed to deliver:

  • A fully functional Linux scientific workstation
  • ATMoS compatibility on x86_64 hardware
  • Automated multi‑run simulation pipeline
  • Secure SSH/SFTP data transfer
  • Publication‑quality graphs and datasets

Technical approach

System rebuild & Linux deployment

The Intel iMac was wiped and rebuilt with Ubuntu Linux, optimised for scientific workloads and long‑term stability.

Scientific environment setup

Installed Python 3.x, ATMoS, and scientific libraries (NumPy, SciPy, Pandas, Matplotlib) in isolated environments to avoid dependency conflicts.

Automated multi‑run pipeline

Developed a Python‑driven workflow to run 108 simulations, manage parameter sweeps, collect outputs, and generate visualisations — converting a manual process into a repeatable automated pipeline.

Secure data transfer

Configured SSH for secure remote access and used SFTP (via Cyberduck) for encrypted transfer of raw outputs, processed datasets, and graphs.

Data analysis & visualisation

Generated radiation flux curves, atmospheric escape rate graphs, time‑dependent evolution plots, and comparative scenario charts — forming the analytical backbone of the dissertation.

Solution delivered

Atkinson IT Ltd delivered a fully functional scientific modelling environment on repurposed legacy hardware, enabling complex ATMoS simulations to run reliably despite platform incompatibilities.
