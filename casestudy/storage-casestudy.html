Storage & Virtualisation Case Study

A case study by Atkinson IT Ltd

Project overview

A large multisite organisation was struggling with ageing storage infrastructure built on legacy RAID arrays and an early‑generation Fibre Channel SAN. The system suffered from poor performance, limited capacity, and no reliable disaster recovery capability.

The environment also included multiple Active Directory forests, mixed Windows and macOS clients, and a growing need for virtualisation. The business required a modern, resilient, scalable storage platform capable of supporting VMware, multidomain file access, snapshots, and multisite replication.

Client context

The organisation operated:

  • Legacy RAID arrays approaching end‑of‑life
  • Early‑generation Fibre Channel SAN
  • VMware virtualisation with performance constraints
  • Mixed Windows/macOS clients
  • Multiple AD forests with no trust relationships

The existing platform could not scale, could not support modern workloads, and had no DR capability.

Challenges

  • Fibre Channel fabric instability
  • No snapshot capability
  • No DR replication or offsite backup
  • Mixed Windows/macOS access issues
  • Multiple AD forests requiring cross‑domain authentication
  • VMware hosts constrained by slow shared storage
  • No self‑service file recovery
  • No centralised management or monitoring

The organisation needed a modern, unified storage platform.

Objectives

The project needed to deliver:

  • Minimal downtime during migration
  • Reuse of existing Fibre Channel infrastructure
  • Support for VMware workloads
  • Cross‑domain authentication for multiple AD forests
  • macOS and Windows file access
  • Snapshots and self‑service recovery
  • Multisite DR with SnapMirror
  • Scalable, resilient storage for future growth

Technical approach

Storage assessment & Fibre Channel audit

  • Analysed RAID performance bottlenecks
  • Mapped Fibre Channel zoning and identified misconfigurations
  • Documented VMware datastore usage
  • Identified cross‑domain authentication issues
  • Assessed macOS SMB/NFS access patterns

NetApp deployment & configuration

I deployed a NetApp FAS system with:

  • High‑performance aggregates
  • RAID‑DP for resilience
  • Multiprotocol support (CIFS/SMB + NFS)
  • Fibre Channel target mode for VMware
  • Snapshots enabled for all volumes

This provided a unified storage platform for all workloads.

VMware integration

  • Configured NetApp LUNs for VMware datastores
  • Migrated VMs using Storage vMotion
  • Improved IOPS and latency across all hosts
  • Enabled thin provisioning and deduplication

Multi‑domain access & virtual file servers

To support multiple AD forests with no trust relationships:

  • Implemented NetApp SVM/vFiler instances
  • Bound each SVM to the appropriate domain
  • Mapped user/group permissions across forests
  • Provided seamless access for Windows and macOS clients

Snapshots & self‑service recovery

  • Hourly, daily, and weekly snapshots
  • Shadow Copies for Windows
  • Snapshot browsing for macOS
  • User‑driven file recovery without IT intervention

Multi‑site mirroring & offsite DR

  • Implemented SnapMirror between primary sites
  • Configured tertiary offsite NetApp for cold‑standby DR
  • Scheduled replication windows to avoid peak usage
  • Tested failover and failback procedures

Fibre Channel stabilisation

  • Cleaned up zoning
  • Removed legacy WWPN entries
  • Normalised fabric configuration
  • Improved path redundancy

Solution delivered

Atkinson IT Ltd delivered a modern, resilient, unified storage platform based on NetApp, stabilised the Fibre Channel fabric, improved VMware performance, and implemented multisite DR with SnapMirror.

Results & impact

  • VMware performance increased by 60–80%
  • Stable file access for Windows and macOS
  • Cross‑domain authentication worked seamlessly
  • Self‑service recovery reduced support load by 40%
  • Snapshots protected against accidental deletion
  • SnapMirror enabled real DR capability
  • Tertiary offsite storage enabled full BCP compliance
  • SAN stability improved significantly

The organisation gained a scalable, enterprise‑grade storage platform.

  • Fibre Channel SAN

  • macOS + Windows mixed environments

Skills demonstrated

Atkinson IT commentary

This project demonstrates how modern storage architecture can transform performance, resilience, and manageability. By combining NetApp, VMware optimisation, and multisite DR, Atkinson IT Ltd delivered a future‑proofed platform that supports the organisation’s long‑term growth.

Lessons learned

This project highlighted how much value can be unlocked by modernising storage without replacing every component. By stabilising Fibre Channel, deploying NetApp, and integrating VMware properly, the organisation gained performance, resilience, and manageability far beyond what the legacy platform could offer.

Frequently asked questions

Why was NetApp chosen?

NetApp provided the best balance of performance, resilience, snapshots, and multisite replication while integrating cleanly with VMware and mixed‑domain environments.

Could the existing Fibre Channel hardware be reused?

Yes. With zoning cleanup and fabric normalisation, the existing SAN infrastructure was stabilised and reused successfully.

How did snapshots improve resilience?

Snapshots enabled instant file recovery, reduced support load, and protected against accidental deletion.

What made VMware faster?

High‑performance NetApp aggregates, deduplication, thin provisioning, and stable Fibre Channel paths all contributed to significantly improved IOPS and latency.

Does this design support future growth?

Yes. The platform is scalable, supports additional SVMs, and can expand storage or replication capacity as needed.
