Storage & Virtualisation Case Study

A Case Study by Atkinson IT Ltd

Overview

A large multisite organisation was struggling with ageing storage infrastructure built on legacy RAID arrays and an early‑generation Fibre Channel SAN. The system suffered from poor performance, limited capacity, and no reliable disaster recovery capability.

The environment also included multiple Active Directory forests, mixed Windows and macOS clients, and a growing need for virtualisation. The business required a modern, resilient, scalable storage platform capable of supporting VMware, multidomain file access, snapshots, and multisite replication.

The Challenge

  • Legacy RAID arrays approaching end‑of‑life
  • Fibre Channel fabric instability
  • No snapshot capability
  • No DR replication or offsite backup
  • Mixed Windows/macOS clients with inconsistent access
  • Multiple AD forests requiring cross‑domain authentication
  • VMware hosts constrained by slow shared storage
  • No self‑service file recovery
  • No centralised management or monitoring

This was limiting the organisation’s ability to scale, virtualise, and protect its data.

Constraints

  • Migration had to occur with minimal downtime
  • Existing Fibre Channel infrastructure needed to be reused
  • Multidomain authentication had to remain intact
  • macOS file access had to be preserved
  • VMware workloads had to remain online
  • DR/BCP solution required multisite replication
  • Budget constraints prevented a full hardware refresh

What I Did

I designed and implemented a NetApp‑based storage architecture to replace the legacy RAID system and stabilise the Fibre Channel environment.

1. Storage Assessment & Fibre Channel Audit

  • Analysed RAID performance bottlenecks
  • Mapped Fibre Channel zoning and identified misconfigurations
  • Documented VMware datastore usage
  • Identified cross‑domain authentication issues
  • Assessed macOS SMB/NFS access patterns

2. NetApp Deployment & Configuration

I deployed a NetApp FAS system with:

  • High‑performance aggregates
  • RAID‑DP for resilience
  • Multiprotocol support (CIFS/SMB + NFS)
  • Fibre Channel target mode for VMware
  • Snapshots enabled for all volumes

This provided a single, unified storage platform for all workloads.

3. VMware Integration

  • Configured NetApp LUNs for VMware datastores
  • Migrated VMs using Storage vMotion
  • Improved IOPS and latency across all hosts
  • Enabled thin provisioning and deduplication

VMware performance improved dramatically.

4. Multi‑Domain Access & Virtual File Servers

The organisation had disparate AD forests with no trust relationships. To solve this:

  • Implemented NetApp vFiler / SVM instances
  • Bound each SVM to the appropriate domain
  • Mapped user/group permissions across forests
  • Provided seamless access for Windows and macOS clients

This allowed each business unit to retain its own identity structure.

5. Snapshots & Self‑Service Recovery

  • Hourly, daily, and weekly snapshots
  • Shadow Copies for Windows
  • Snapshot browsing for macOS
  • User‑driven file recovery without IT intervention

This reduced support tickets and improved resilience.

6. Multi‑Site Mirroring & Offsite DR

  • Implemented SnapMirror between primary sites
  • Configured a tertiary offsite NetApp for cold‑standby DR
  • Scheduled replication windows to avoid peak usage
  • Tested failover and failback procedures

This created a three‑tier resilience model:

  • Local snapshots
  • Intersite replication
  • Offsite tertiary DR storage

7. Fibre Channel Stabilisation

  • Cleaned up zoning
  • Removed legacy WWPN entries
  • Normalised fabric configuration
  • Improved path redundancy

This eliminated SAN instability.

Outcome

  • VMware performance increased by 60–80%
  • Stable file access for Windows and macOS
  • Cross‑domain authentication worked seamlessly
  • Self‑service recovery reduced support load by 40%
  • Snapshots protected against accidental deletion
  • SnapMirror enabled real DR capability
  • Tertiary offsite storage enabled full BCP compliance
  • SAN stability improved significantly

The organisation gained a modern, resilient, scalable storage platform that supported virtualisation, multidomain access, and enterprise‑grade DR.
