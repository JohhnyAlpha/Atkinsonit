Virtualisation & Server Consolidation Case Study

A case study by Atkinson IT Ltd

Project overview

A large organisation was operating several hundred physical servers delivering web services, databases, and line‑of‑business applications. The environment had grown organically, resulting in high costs, poor utilisation, inconsistent performance, and no safe upgrade path.

The business needed a modern, scalable, resilient virtualisation platform capable of supporting mixed workloads with zero downtime. Atkinson IT Ltd designed and deployed a VMware‑based solution that consolidated the entire estate into a high‑performance virtual infrastructure.

Client context

The organisation faced:

  • Hundreds of underutilised physical servers
  • No centralised management or monitoring
  • No load balancing or failover capability
  • Long provisioning times for new services
  • High operational overhead and power usage
  • No cloning or snapshot capability
  • Inconsistent network configuration across racks

The existing environment could not scale and was becoming increasingly difficult to maintain.

Challenges

  • Zero downtime required during migration
  • Mixed workloads had to remain online
  • Existing network infrastructure had to be reused
  • VLANs needed to be introduced without breaking legacy systems
  • Development teams required clone‑ready environments
  • Platform needed to support auto‑migration and load balancing

Objectives

The virtualisation platform needed to deliver:

  • High‑density server consolidation
  • Centralised management and monitoring
  • Automated load balancing and failover
  • Zero‑downtime maintenance
  • Rapid provisioning for development and testing
  • Network segmentation via VLANs
  • Improved performance and reliability

Technical approach

Hardware consolidation

  • Selected 15 high‑density, multi‑CPU, high‑RAM servers
  • Implemented shared storage for VM mobility
  • Reduced physical footprint by over 85%

VMware virtualisation platform

  • Deployed VMware ESXi across all hosts
  • Configured vCenter for centralised management
  • Enabled DRS for auto‑migration and load balancing
  • Enabled HA for automatic failover

Virtual networking with VLAN tagging

  • Web VLAN
  • Database VLAN
  • Application VLAN
  • Management VLAN
  • Backup VLAN
  • Storage VLAN

NIC teaming & redundancy

  • Implemented NIC teaming for bandwidth aggregation
  • Provided failover protection for network paths
  • Ensured uninterrupted connectivity during maintenance

Load balancing & auto‑migration

  • Workloads automatically moved to the least‑loaded host
  • CPU and RAM utilisation balanced across the cluster
  • Hot migrations enabled zero‑downtime maintenance

Clone‑based development environments

  • Created golden images for web, DB, and app servers
  • Enabled rapid cloning for development and testing
  • Reduced provisioning time from days to minutes

Zero‑downtime upgrades

  • Hosts patched one at a time
  • VMs migrated automatically
  • No service interruptions
  • No out‑of‑hours maintenance windows

Solution delivered

Atkinson IT Ltd delivered a modern VMware virtualisation platform running on 15 high‑capacity servers, replacing hundreds of physical machines and enabling a fully automated, resilient, scalable infrastructure.

Results & impact

  • Server count reduced by 85–90%
  • Performance increased by 50–200%
  • Power and cooling costs dropped significantly
  • Deployment time reduced from days to minutes
  • Zero‑downtime upgrades became standard
  • Load balancing improved reliability
  • Development teams gained instant clone‑ready environments
  • Network segmentation improved security

The organisation gained a scalable, high‑performance virtualisation platform.

  • High‑density server hardware

  • VLAN tagging (802.1Q)

  • HA failover
  • Clone‑based provisioning

Skills demonstrated

  • Server consolidation strategy

  • Performance optimisation

Frequently asked questions

How did you achieve zero downtime?

VMware vMotion allowed live migration of workloads between hosts, enabling maintenance without service interruption.

Why only 15 servers?

High‑density, multi‑CPU, high‑RAM hosts provided enough capacity to replace hundreds of legacy machines.

How does DRS help?

DRS automatically balances workloads across the cluster, improving performance and reliability.

What benefits did VLANs provide?

Segmentation improved security, reduced broadcast traffic, and simplified troubleshooting.

Can this platform scale further?

Yes. Additional hosts, storage, and VLANs can be added without redesigning the architecture.
